# xddcube

> Because "why not?"

For something that is actually useful, see [vkcube](https://github.com/krh/vkcube).

This use Vulkan and GLFW to show a spinning cube of a certain meme that I do not know the name of.
Is an excuse to learn about Vulkan. Was fun, but the API is really, really verbose.
Probably could make a simple 3D engine after this!

There might be a lot more to improve here, but for a meme, this is good enough.
Maybe one day I might come back and add some random fluff to it.

## Building

Dependencies:

- [GLFW](https://www.glfw.org/) and its dependencies for your platform
- Vulkan development headers
- [cglm](https://github.com/recp/cglm) headers
- [stb_image.h](https://github.com/nothings/stb)
- make (or whatever build system you prefer)
